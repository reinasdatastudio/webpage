グラフのコードが長くなるほど難しくなり、ちゃんと理解していないと何がどうなっているのかわからなくなります。

ggplot2とは

簡単にいえば、一番Rで使われている、データを可視化するツールです。コードでいろんなグラフを作ったり、もっと細かく色やデザインなども変えることができます。使いこなせたらきれいなレポートを作れます。

基本のコード

すべてのggplot2は基本のコードがあります。

ggplot(data = <DATA>, mapping = aes(<GLOBAL_MAPPINGS>)) +
  <GEOM_FUNCTION>(mapping = aes(<LOCAL_MAPPINGS>)...) +
  <STAT_FUNCTION>(...) +
  <SCALE_FUNCTION>(...) + 
  <COORD_FUNCTION>(...) +
  <FACET_FUNCTION>(...) +
  labs(
    title = <TITLE>,
    subtitle = <SUBTITLE>,
    x = <X_LABEL>,
    y = <Y_LABEL>,
    caption = <CAPTION>) +
  <THEME_FUNCTION>(...)

こうみると難しくみえますが、一番ベーシックなグラフを作るにあたって必ず必要なのは、

ggplot(data = <DATA>, mapping = aes(<GLOBAL_MAPPINGS>)) +
  <GEOM_FUNCTION>(mapping = aes(<LOCAL_MAPPINGS>)...)

の部分だけです。

さっそく例えとして、irisデータを使います。

scatterplotで、sepal（がく片）とpetal（花びら）の長さを比べます。

ggplot(data = iris, mapping = aes(x = Sepal.Length, y = Petal.Length)) +
  geom_point()

同じグラフでも、いろんなものを付け足せます。

ggplot(iris, aes(x=Sepal.Length, y=Petal.Length)) +
  geom_jitter(aes(fill = Species, shape = Species),
              shape = 21,
              color = "black",
              size = 2,
              stroke = 0.8, #border thickness
              alpha = 0.9) + #transparency
    scale_fill_manual(values = c("setosa" = "pink", 
                                 "versicolor" = "#2A9D8F",
                                 "virginica" = "purple")) +
  scale_x_continuous(labels  = function(x) paste0(x, "cm")) +
  scale_y_continuous(labels = function(x) paste0(x, "cm")) +
  labs(title = "Sepal Length vs Petal Length") +
  theme_minimal(base_size = 10) +
  theme(
    text = element_text(family = "Georgia")
  )

もっと：

interactive_iris_plot <- iris |>
  dplyr::rename_with(~ gsub(".", " ", .x, fixed = TRUE)) |>
    ggplot(aes(x=`Sepal Length`, y=`Petal Length`)) +
      geom_jitter_interactive(aes(fill = Species,
                                  tooltip = paste0("Sepal Length: ",
                                                  `Sepal Length`,
                                                  "cm",
                                                  "\nPetal Length: ",
                                                  `Petal Length`,
                                                  "cm")),
                              shape = 21,
                              color = "black",
                              size = 2,
                              stroke = 0.8, #border thickness
                              alpha = 0.9,  #transparency
                              ) +
      scale_fill_manual(values = c("setosa" = "pink", 
                                     "versicolor" = "#2A9D8F",
                                     "virginica" = "purple")) +
      coord_fixed(ratio = 1) + #Keeping x and y equal aspect ratio
      scale_x_continuous(labels  = function(x) paste0(x, "cm")) +
      scale_y_continuous(breaks = seq(0, 10, by = 1),labels = function(x) paste0(x, "cm")) +
      labs(title = "Sepal Length vs Petal Length") +
      theme_minimal(base_size = 12) +
      theme(
        text = element_text(family = "Georgia"),
        plot.title.position = "panel",
      )

girafe(ggobj = interactive_iris_plot)
