再現性のあるデータ分析の実践ガイド（R）

Reproducibility
Rで再現性のあるデータ分析を行うための基本を解説します。プロジェクトの整理方法やスクリプトの使い方、Quartoによるレポート作成など、実務で役立つ内容をまとめています。
Published

April 20, 2026

データ分析を行うとき、多くの場合「結果を出すこと」に集中しがちです。

しかし、研究や実務において非常に重要なのが再現性（reproducibility） です。

再現性とは：

同じデータとコードを使えば、誰でも同じ結果を再現できる状態

この記事では、再現性のある分析とは何か、そしてRでどのように実践するかを、実務に近い形で紹介します。

なぜ再現性が重要なのか

実際の分析では、次のような場面がよくあります：

  • 数週間後に分析を見直す
  • 新しいデータで結果を更新する
  • 他の人と結果を共有する
  • 分析の正しさを確認する

再現性がないと：

  • どのように結果を出したか分からなくなる
  • ミスに気づきにくい
  • 分析を再利用できない

よくあるのが：

「前にこの結果出したけど、どうやったか分からない」

という状態です。

再現性のあるワークフローはこれを防ぎます。

再現性のある分析とは

再現性のある分析には、以下の要素があります：

  1. 手作業ではなくスクリプトで処理する
  2. 分析の構造が整理されている
  3. 最初から最後まで実行できる
  4. 同じ結果が再現できる

Rでは、これらは比較的シンプルに実現できます。

1. 手作業ではなくスクリプトで行う

よくある問題：

  • Excelで手作業で編集
  • コードをその場で実行するだけ
  • 結果を手動でコピー

これを避け、すべてコードで管理します。

data <- read.csv("data.csv")
data_clean <- data |>
  dplyr::filter(!is.na(value))
model <- lm(value ~ age, data = data_clean) 
summary(model)

これにより：

  • 手順がすべて記録される
  • 再実行が可能になる

2. プロジェクト構造を整理する

シンプルな構成で十分です：

project/
  data/
  scripts/
  output/
  report.qmd

project/の中に：

  • data → データ
  • scripts → 分析コード
  • output → 結果
  • report → レポート

整理されているだけで、再現性は大きく向上します。

3. データ処理と分析を分ける

データ前処理と分析は分けると管理しやすくなります。

# scripts/01_clean_data.R
clean_data <- raw_data |> 
  dplyr::filter(!is.na(value))
# scripts/02_analysis.R
model <- lm(value ~ age, data = clean_data)

メリット：

  • 再利用しやすい
  • デバッグしやすい
  • データ更新が簡単

4. Quarto / R Markdownを使う

レポートを手作業で作るのではなく、コードから生成します。

## モデル結果
summary(model)

再実行すると、結果が自動更新される。

これは再現性の中でも特に重要なポイントです。

5. パスを固定しない

以下のようなコードは避けます：

read.csv("C:/Users/xxx/Desktop/data.csv")

代わりに：

read.csv("data/data.csv")

これで他の環境でも動くようになります。

6. 最初から実行して確認する

とてもシンプルですが重要です：

  • Rを再起動
  • 最初から実行

問題なく動けば再現性あり。

7. 考え方も記録する

コードだけでなく、意図も残します。

# 欠損値を除外（モデルに影響するため）
data_clean <- data |>
  dplyr::filter(!is.na(value))

これにより：

  • 他人が理解しやすい
  • 自分も後で理解できる

よくある問題

  • コードを保存していない
  • 手作業が多い
  • データと分析が混ざっている
  • ファイル構造が不明確

こういった状態では再現が難しくなります。

まとめ

再現性は特別な技術ではなく：

  • スクリプトで管理する
  • 構造を整理する
  • 自動化する

といった基本の積み重ねです。

完璧である必要はありませんが、

「もう一度同じ結果を出せるか？」

という視点を持つことが重要です。
