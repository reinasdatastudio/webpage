ggplot入門③：よく使うグラフの種類

前回の記事では、ggplotの基本構造について説明しました。

今回は、実際に どのグラフを使えばよいのか を見ていきます。

第一回でも説明したように、データのタイプ（連続値・離散値）によって適切なグラフは変わります。

グラフの選び方（まとめ）

まず簡単にまとめると、タイプによって使うグラフは次のようになります。

データのタイプ グラフ ggplot
離散値1つ 棒グラフ geom_bar()
連続値1つ ヒストグラム geom_histogram()
連続値1つ 密度プロット geom_density()
連続値1つ 頻度ポリゴン geom_freqpoly()
連続値1つ 面グラフ geom_area()
連続値1つ ドットプロット geom_dotplot()
連続値2つ 散布図 geom_point()
連続値2つ ジッタープロット geom_jitter()
連続値2つ 回帰線・平滑線 geom_smooth()
連続値2つ ラベル付き散布図 geom_text() / geom_label()
離散値 + 連続値 箱ひげ図 geom_boxplot()
離散値 + 連続値 バイオリンプロット geom_violin()
離散値 + 連続値 ポイントレンジ geom_pointrange()
離散値 + 連続値 エラーバー geom_errorbar()

もちろん、すべてを覚える必要はありません。

実際のデータ分析でよく使うグラフは主に次の5つです。

データのタイプ グラフ ggplot
離散値1つ 棒グラフ geom_bar()
連続値1つ ヒストグラム geom_histogram()
連続値1つ 密度プロット geom_density()
連続値2つ 散布図 geom_point()
離散値 + 連続値 箱ひげ図 geom_boxplot()

まずはこの5つを覚えるだけでも、ほとんどのデータを可視化できます。

ここから、それぞれの例を見ていきましょう。

離散値が1つの場合

棒グラフ

離散値（カテゴリー）を1つだけ見る場合は、棒グラフ（bar chart）をよく使います。

例えば、irisデータでは Species が離散値です。

ggplot(iris, aes(x = Species)) +
  geom_bar()

このグラフでは、それぞれの種類（Species）が何件あるかを見ることができます。

連続値が1つの場合

ヒストグラム

連続値の分布を見るときは、ヒストグラム（histogram）がよく使われます。

例えば、がく片の長さ（Sepal.Length）を見てみます。

ggplot(iris, aes(x = Sepal.Length)) + 
  geom_histogram(binwidth = 0.2)
# binwidthとは、区間（bin）の幅を表しています。
# 小さい値 = 細かいヒストグラム
# 大きい値 = 大まかなヒストグラム

ヒストグラムでは、データがどの範囲に多く分布しているかを見ることができます。

密度プロット

同じく分布を見る方法として、密度プロット（density plot）があります。

ggplot(iris, aes(x = Sepal.Length)) +
  geom_density(adjust = 1)
# adjustとは、密度曲線のスムージングの強さを調整するパラメーターです。
# 小さい値 = ギザギザの曲線
# 大きい値 = なめらかな曲線

ヒストグラムよりもなめらかな分布を見ることができます。

連続値が2つの場合

散布図

2つの連続値の関係を見るときは、散布図（scatterplot）を使います。

ggplot(iris, aes(x = Sepal.Length, y = Petal.Length)) +
  geom_point()

散布図では、2つの変数の関係（相関など）を見ることができます。

離散値 + 連続値

箱ひげ図

離散値と連続値を比較するときは、箱ひげ図（boxplot）がよく使われます。

ggplot(iris, aes(x = Species, y = Sepal.Length)) +
  geom_boxplot()

このグラフでは、種類ごとのSepal.Lengthの分布を比較することができます。

このように、データ分析では「どのグラフを使うべきか」を考えることがとても大切です。

そのため、まずデータのタイプを理解する → 適切なグラフを選ぶという流れを意識してみてください。
