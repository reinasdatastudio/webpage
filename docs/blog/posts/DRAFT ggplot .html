Understanding ggplot2

  • aes within ggplot() vs geom_*() - local vs global aesthetics
  • Basic 7 layers - first 2 must be memorised
  • color = “your class variable”, or do size or shape instead
    • outside aes() if you are specifying color such as “pink”
  • what is facets? useful especially for categorical values

Great question. In ggplot2, plots are built by layering components. There isn’t one strict “equation”, but there is a common grammar template that most plots follow.

Below is a complete conceptual skeleton of a ggplot.

1. Full ggplot Template (Grammar of Graphics)

ggplot(data = <DATA>, mapping = aes(<GLOBAL_MAPPINGS>)) +    <GEOM_FUNCTION>(     mapping = aes(<LOCAL_MAPPINGS>),     stat = <STAT>,     position = <POSITION>,     ...   ) +    <STAT_FUNCTION>(...) +    <SCALE_FUNCTION>(...) +    <COORD_FUNCTION>(...) +    <FACET_FUNCTION>(...) +    <THEME_FUNCTION>(...) +    labs(     title = <TITLE>,     subtitle = <SUBTITLE>,     x = <X_LABEL>,     y = <Y_LABEL>,     caption = <CAPTION>   )

2. The Main Components of ggplot

Think of ggplot as 7 major layers.

DATA ↓ AESTHETICS ↓ GEOMS ↓ STATS ↓ SCALES ↓ COORDINATES ↓ FACETS ↓ THEME / LABELS

3. Data

ggplot(data = <DATA>)

Example

ggplot(data = mpg)

You can also pipe data:

mpg %>% ggplot(aes(x = displ, y = hwy))

4. Aesthetics (aes)

Maps variables → visual properties.

aes(   x,   y,   color,   fill,   size,   shape,   alpha,   group,   linetype )

Example

aes(x = displ, y = hwy, color = class)

5. Geoms (the actual plot type)

geom_<type>()

Common ones:

geom purpose
geom_point() scatterplot
geom_line() line plot
geom_bar() bar plot
geom_col() bar with values
geom_histogram() histogram
geom_boxplot() boxplot
geom_violin() violin plot
geom_density() density
geom_smooth() regression
geom_area() area chart
geom_text() labels

Example:

geom_point()

6. Statistics (stat)

Transforms the data before plotting.

Example:

stat_summary() stat_bin() stat_smooth()

Example inside geom:

geom_bar(stat = "count")

or

geom_bar(stat = "identity")

7. Position Adjustments

How elements overlap.

position = "identity" position = "stack" position = "dodge" position = "fill" position = "jitter"

Example:

geom_bar(position = "dodge")

8. Scales (controls axes, colors, legends)

scale_<aesthetic>_<type>()

Examples:

scale_x_continuous() scale_y_log10() scale_color_manual() scale_fill_brewer() scale_size_continuous() scale_alpha()

Example

scale_color_manual(values = c("red", "blue"))

9. Coordinates

How the plot space is drawn.

coord_cartesian() coord_flip() coord_fixed() coord_polar() coord_sf()

Example

coord_flip()

10. Facets (small multiples)

Split plots by variable.

facet_wrap(~ variable)  facet_grid(rows ~ columns)

Example

facet_wrap(~ class)

11. Labels

labs(   title = "",   subtitle = "",   x = "",   y = "",   caption = "",   color = "",   fill = "" )

Example

labs(   title = "Fuel efficiency",   x = "Engine size",   y = "Highway MPG" )

12. Themes

Controls appearance.

theme()  theme_bw() theme_minimal() theme_classic() theme_void()

Example

theme_minimal()

13. Realistic Full Example

ggplot(data = mpg, aes(x = displ, y = hwy, color = class)) +
 geom_point(size = 3, alpha = 0.7) +
 geom_smooth(method = "lm", se = FALSE) +
 scale_color_brewer(palette = "Set2") +
 coord_cartesian() +
 facet_wrap(~ drv) +
 labs(
  title = "Engine Size vs Fuel Efficiency",
  x = "Engine Displacement",
  y = "Highway MPG",
  color = "Vehicle Class") +
theme_minimal()

14. The One-Line Mental Model

Most ggplots follow this structure:

ggplot(data, aes()) + geom_*() + scale_*() + facet_*() + coord_*() + labs() + theme()
